# Rooftop Patang sounds

The game loads these files by name (see `SAMPLES` in `../index.html`). Anything missing falls back to the
game's synthesised version of that sound.

| File | Used for |
|------|----------|
| `freesound_community-crowd-cheering-6229.mp3` | the cheer when you cut a kite, and a quieter one when the neighbours cut each other |
| `storegraphic-soft-wind-477404.mp3` | the breeze, built from overlapping slices of the clip, louder in strong wind |
| `freesound_community-distant-firework-barrage-aerial-cake-35808.mp3` | short pieces of it for each firework at night |
| `kaipoche.mp3` | not added yet: someone shouting "kai po che!" when you cut a kite |
| `whistle.mp3` | not added yet: crowd whistles after the cheer |

The first three come from Pixabay; check their licence pages before publishing the game.
